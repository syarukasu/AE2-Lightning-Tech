# AE2 Lightning Tech - Unofficial Forge 1.20.1 Port

This project is an independent, unofficial Forge 1.20.1 port of
[AE2 Lightning Tech](https://github.com/ae2lt/AE2-Lightning-Tech), an Applied
Energistics 2 add-on focused on lightning power, advanced processing machines,
and overloaded ME network components.

This port is not maintained, sponsored, or endorsed by the original AE2
Lightning Tech authors or by the Applied Energistics 2 team. The original
NeoForge project remains the canonical upstream project. The upstream
CurseForge and Modrinth pages distribute that NeoForge edition, not this Forge
1.20.1 port.

## Features

- Capture lightning and store it as High Voltage or Extreme High Voltage
  lightning energy.
- Produce and process lightning with collectors, multiblock machines, and the
  Tesla Coil.
- Grow and process Overload Crystals through a complete material progression.
- Use the Lightning Assembly Chamber, Lightning Simulation Room, Overload
  Processing Factory, Crystal Catalyzer, and Firmament Conversion systems.
- Build overloaded ME controllers, interfaces, pattern providers, cables, and
  wireless pattern-routing networks.
- Equip Celestweave armor and the Electromagnetic Railgun.
- Read the included English, Simplified Chinese, and Japanese AE2 Guide pages.

## Required environment

- Minecraft 1.20.1
- Forge 47.4.20 or newer within the Forge 47 series
- Java 17
- Applied Energistics 2 15.4.10 through 15.4.x

Applied Energistics 2 is required. Optional integrations are available for
Jade, JEI, AE2 Wireless Terminals, Advanced AE, ExtendedAE, Applied Flux,
Mekanism, Curios, Neo ECO AE Extension, Flywheel, and Ponder when compatible
versions are installed.

## Current and planned releases

The current stable Forge line is based on upstream AE2LT 1.1.4. A feature-by-
feature Forge 1.20.1 backport of upstream AE2LT 2.0.6 is planned and tracked on
GitHub. The NeoForge 2.0.6 JAR is not directly compatible with Forge 1.20.1.
