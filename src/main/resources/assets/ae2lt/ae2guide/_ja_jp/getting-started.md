# はじめに

このページでは、最初から稼働する最初の ライトニング生産ラインまでの完全な手順を説明します。

## 前提条件

開始する前に、少なくとも以下を含む機能する AE2 MEネットワーク が既にあることを確認してください。

* <ItemLink id="ae2:controller" />、または小規模なコントローラーレス ネットワーク
* いくつかの <ItemLink id="ae2:certus_quartz_crystal" />、<ItemLink id="ae2:fluix_crystal" />、および <ItemLink id="ae2:fluix_block" />
* の <ItemLink id="minecraft:lightning_rod" /> およびさまざまな層の一部の AE2の芽生えたケルタスクォーツ

## ステップ 1: オーバーロードクリスタル を取得する

<ItemImage id="ae2lt:overload_crystal" scale="2" float="left" />

**オーバーロードクリスタル** は、この MOD の最も基本的なマテリアルです。ほぼすべてのレシピがこれまたはその派生品の 1 つに依存しています。

あなたは、**芽生えたオーバーロードクリスタル** ブロックを成長させることで入手できます。ブロックは、マルチブロック雷の儀式によって AE2の芽生えたケルタスクォーツ から生成されます。

1. 出芽したクォーツを中心に3×3の構造を組み立てます。リッチ バリアントでは、4 隅に <ItemLink id="ae2lt:overload_crystal_block" /> が使用され、4 つの基本的な側面に <ItemLink id="ae2:fluix_block" /> が使用されます。単純なバリアントでは、側面の流体を維持しながら、コーナーを <ItemLink id="ae2:quartz_block" /> (ケルタスクォーツブロック) と交換します。
2. 中央の真上に <ItemLink id="minecraft:lightning_rod" /> を配置します
3. 落雷 を待ちます — リッチ バリアントには 自然発生の雷 が必要です。シンプルな フルーシュ のみのバリアントでは、あらゆる稲妻が機能します
4. 結果として得られる **芽生えたオーバーロードクリスタル** をワールドに配置し、その表面に芽が成長するのを待ちます

芽生えたオーバーロードクリスタル は 芽生えたケルタスクォーツ と同じように動作します。

* 芽は順に成長します: 小 → 中 → 大 → **オーバーロードクリスタルの塊**
* <ItemLink id="ae2:growth_accelerator" /> は オーバーロードクリスタル のつぼみにも機能します
* **完全に成長する前**の芽を壊すと、**オーバーロードクリスタルの粉**をドロップします
* 完全に成長した**オーバーロードクリスタルの塊**を壊すと、**オーバーロードクリスタル**をドロップします。幸運エンチャントも有効です
* 不完全な出芽ブロックは、芽が成長するたびに 1 層減衰する可能性があります。採掘されると、シルクタッチ は欠陥、ひび割れ、損傷した層を保持します。 完璧 が 傷あり としてドロップされる

詳細については、[オーバーロードクリスタル](materials/overload-crystal.md) を参照してください。

## ステップ 2: ライトニング変換 経由でスターター材料を入手します

多くのスターターマテリアルは **ライトニング変換** を通じて生成されます。アイテムを地面にドロップし、そのドロップを 落雷 で変換させます。

<ItemImage id="ae2lt:overload_alloy" scale="2" float="left" />

一般的な変換出力には次のものがあります。

* **オーバーロード合金**、**オーバーロード回路基板**、 **オーバーロード刻印プレス**およびその他の基本資料
* **ライトニングコレクター**、**ライトニングシミュレーション室**とマシンの第一波
* **雷鳴クリスタル** および **ライトニングストレージセル I**、ライトニングシステムのスターター アイテム

稲妻変換をトリガーするには 2 つの方法があります:

* **自然雷雨**: 雷雨の天候では、屋外のアイテムドロップが自然発生の雷によって攻撃される可能性があります。
* **アクティブ召喚**: オーバーロードクリスタルを持ち歩き、屋外に約10秒間立って近くに人工雷ボルトを召喚します

> 人工雷でも変換レシピは起動できますが、次のステップにあるマルチブロック変換は**起動できません**。マルチブロック変換が受け入れるのは自然落雷だけです。

## ステップ 3: 完璧な芽生えたオーバーロードクリスタル を取得する

<ItemImage id="ae2lt:flawless_budding_overload_crystal" scale="2" float="left" />

**完璧な芽生えたオーバーロードクリスタル** は成長中に減衰せず、大規模生産ラインのバックボーンです。 **リッチ構造**バリアントと **自然落雷** を使用してのみ生成できます。

<GameScene zoom="4" background="transparent">
  <ImportStructure src="assets/assemblies/flawless_budding_overload.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

* **完璧な芽生えたケルタスクォーツ**を中央に配置します
* <ItemLink id="ae2:fluix_block" /> を 4 つの基本的な側面 (E / W / N / S) のそれぞれに同じ高さに配置します。
* **オーバーロードクリスタルブロック**を四隅のそれぞれに配置します
* **避雷針**を中心の真上に配置します

構造が構築されたら、**自然落雷** が 避雷針 にヒットして変換が完了するまで待ちます。ストライクが着地すると、周囲の8つのブロックが消費され、中央のブロックが完璧な芽生えたオーバーロードクリスタルになります。

> 完璧な変換は、雷雨の間、**自然発生の雷** のみを受け入れます。 オーバーロードクリスタルを運ぶことで召喚された人工雷は誘発しません。下層の出芽結晶には、[オーバーロードクリスタル](materials/overload-crystal.md) ページで説明されている安価な「単純な構造」のバリアントがあります。

## ステップ 4: 最初の ライトニング行を構築する

スターターマテリアルと基本的なマシンを用意したら、実行可能な最小限のラインをまとめることができます: **収集 → 保管 → 消費**。

1. **収集**: **ライトニングコレクター**を屋外に置き、MEネットワークに接続します。 落雷 の場合、コレクターは ライトニングエネルギー をネットワークに直接注入します
2. **保管**: **ライトニングストレージセル I**を<ItemLink id="ae2:drive" />へ入れます。ライトニングはアイテムや液体とともにMEターミナルへ表示されます
3. **消費**: **ライトニングシミュレーション室**と**ライトニング組立室**は、レシピ実行時にMEネットワーク内のライトニングを消費します

便利なサポートデバイス:

* [テスラコイル](lightning/tesla-coil.md) — オーバーロードクリスタルの粉とFEを消費し、高電圧／超高電圧ライトニングを安定して生成します
* [大気イオン化装置](machines/atmospheric-ionizer.md) — AE エネルギーと **天候凝縮液** を消費して世界の天気を強制的に変化させます

## ステップ 5: ゲーム中盤および終盤の目標

スターター ラインが実行されると、順番に次のロックを解除できます。

* **ライトニングシミュレーション室** (3 入力スロット、単純な変換) および **ライトニング組立室** (9 入力スロット、複雑なアセンブリ)
* **オーバーロード処理工場** (9 つの入力スロット、アイテム + 流体 I/O、および ライトニング崩壊マトリクス による並列処理をサポート)
* **結晶触媒装置** (水 + スロットアイテム、クリスタル / ダストモード付き)
* **オーバーロードMEコントローラー** - 各コントローラーはネットワークに 128 チャネルを追加します
* **オーバーロードケーブル** - 単一のケーブルにはケーブルごとのチャネル制限はありません
* **オーバーロードパターンプロバイダー** および **オーバーロードMEインターフェース** - それぞれ 36 スロット、無線ディスパッチと無線 I/O

詳細については、左側のサイドバーにあるカテゴリ ページを参照してください。
