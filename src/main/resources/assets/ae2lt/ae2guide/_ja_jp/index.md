# AE2 Lightning Tech

AE2 Lightning Techは、Applied Energistics 2を拡張するMODです。MEネットワークへ新たなストレージ種別である**ライトニング**を追加し、専用の素材系統と加工機械、通常のチャンネル制限を越える「オーバーロード」系ネットワーク機器を導入します。

主な特徴:

* 自然または機械で生成された稲妻を **ライトニングエネルギー** として収集し、アイテムや液体と一緒に MEネットワーク に保管します
* ライトニングを使用して、オーバーロード合金、オーバーロードプロセッサ、ライトニング崩壊マトリクス、およびその他の新しい材料を生産する高度な加工機械に電力を供給します
* オーバーロードMEコントローラー、オーバーロードケーブル、オーバーロードパターンプロバイダー、および オーバーロードMEインターフェース を使用して、MEネットワーク のチャンネル容量と範囲を拡大します。
