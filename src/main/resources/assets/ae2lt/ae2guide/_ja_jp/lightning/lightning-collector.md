# ライトニングコレクター

<Row>
  <BlockImage id="ae2lt:lightning_collector" scale="4" />
</Row>

**ライトニングコレクター**は、ライトニングシステムの出発点です。**コレクター直上の避雷針**へ落雷すると、ライトニングエネルギーをMEネットワークへ直接注入します。

## 基本的な使用法

ライトニングコレクターを**屋外へ設置**し、その真上へ通常の**避雷針を直接置いて**、コレクターをMEネットワークへ接続します。直上の避雷針へ落ちた雷だけを回収するため、自然の雷雨を受けられるよう避雷針の上空を開けてください。

ストライキが生産的であるためには、次の 3 つの条件を満たす必要があります。

* 避雷針 はコレクターの真上のブロックに配置する必要があります
* ネットワークがオンラインである必要があります
* ネットワークには、生成される ライトニングを受け入れるのに十分なストレージ容量が必要です (そうでない場合、ストライクは無駄になります)

生成される ライトニングの階層は、何が最上位に当たるかによって異なります 避雷針:

* **人工雷** (オーバーロードクリスタルを所持しているプレイヤーによって召喚されるか、テスラコイルによって排出される) → **高電圧ライトニング**
* **自然発生の雷** (本物の雷雨ボルト) → **超高電圧ライトニング**

収集が成功するたびに、コレクターは短いクールダウンに入ります (デフォルトは 0 ティック、構成可能)。

## 雷鳴クリスタル と収量

<ItemImage id="ae2lt:electro_chime_crystal" scale="2" float="left" />

コレクターには専用の**クリスタルスロット**があり、**雷鳴クリスタル**を装着できます。クリスタルの有無と育成段階によって、落雷1回あたりの収量が決まります。

| 結晶状態 | 収量 |
|---------------|-------|
| クリスタルなし | 固定の**基本範囲**内でランダム（初期値はHV 1～2、EHV 1～4） |
| 栽培 雷鳴クリスタル | 栽培の進行に応じて「開始収量」と「最終収量」の間で直線的にスケールし、さらに小さなランダムなジッターも発生します |
| 完全な雷鳴クリスタル | **固定利回り** (HVとEHVの両方でデフォルトは16)、ランダム性なし |

## 雷鳴クリスタル を栽培する

雷鳴クリスタル は、栽培値に基づいて 4 つの段階を経て進行します。

| ステージ | 進捗状況 |
|-------|----------|
| 休眠中 | < 20% |
| 撹拌中 | 20% ~ 55% |
| 共鳴 | 55% ～ 85% |
| 過充電されました | ≥ 85% |

* クリスタルは、コレクターが **自然発生の雷** (超高電圧ライトニングを生み出す攻撃) を受けた場合にのみ育成価値を獲得します。 人工雷は栽培に貢献しません
* 栽培値が最大に達すると、雷鳴クリスタル は自動的に **完全な雷鳴クリスタル** に変換されます。
* 完全な雷鳴クリスタル はそれ以上の栽培は行わなくなりましたが、安定した最大収量を提供します

## 自動化のヒント

* コレクターはそのすぐ上に 避雷針 があり、オンライン MEネットワーク に接続されている必要があります。そうでない場合、落雷 は無駄になります
* 自然の雷雨を待ちたくない場合は、[大気イオン化装置](../machines/atmospheric-ionizer.md) と 雷雨凝縮液 を併用して雷雨の天候を強制します
* 完全に天候に依存しないソリューションの場合、[テスラコイル](tesla-coil.md) を使用して HV / EHV ライトニングをオンデマンドで生成します
