# ライトニングシステム

ライトニングは、この MOD が MEネットワーク に追加する新しいストレージ タイプです。アイテムや液体と同様に、ターミナルでその量を確認し、貯蔵セル内に保管し、処理機械に消費させることができます。

## 2 層

| ティア | 製造方法 |
|------|---------------------|
| **高電圧ライトニング** | A ライトニングコレクター が **人工雷** にヒット (オーバーロードクリスタル を所持しているプレイヤーによって召喚されるか、テスラコイル によって排出される) |
| **超高電圧ライトニング** | ライトニングコレクター **自然発生の雷** (本物の雷雨ボルト) によって攻撃された、または テスラコイル アップコンバートによって生成された 高電圧ライトニング |

ほとんどの基本的なレシピには 高電圧ライトニングのみが必要です。いくつかの高度なレシピでは超高電圧が必要です。 **ライトニング崩壊マトリクス** がインストールされている場合、一部の EHV レシピは、HV ライトニングの数倍の量で置き換えることができます。
