# ライトニングストレージセル

ライトニングストレージセル は、MEネットワーク に ライトニングを保持するための専用の記憶媒体です。通常のアイテム/液体貯蔵セルと同様に、1 つを <ItemLink id="ae2:drive" /> にドロップするだけで使用を開始できます。

## 階層

ライトニングストレージセルは5段階あり、ティアが上がるほど容量が増えます。1個のセルに**高電圧ライトニングと超高電圧ライトニングの両方**を同時に保存できます。

| ティア | 実効容量 | アイドルドレン |
|------|--------------------|------------|
| ライトニングストレージセル 私 | 256 | 32 AE/t |
| ライトニングストレージセル II | 1,024 | 128 AE/t |
| ライトニングストレージセル III | 4,096 | 512 AE/t |
| ライトニングストレージセル IV | 16,384 | 2,048 AE/t |
| ライトニングストレージセル V | 65,536 | 8,192 AE/t |

## 無限 ストレージセル

<ItemImage id="ae2lt:infinite_storage_cell" scale="2" float="left" />

**無限 ストレージセル** には容量制限がなく、一度に任意の量の任意の種類のアイテムを保持できます。製作コストと必要な技術のため、**大量生産することはできません**。
