# 加工機

AE2 Lightning Techには、素材系統ごとの加工機械があります。MEネットワークからAEエネルギーを消費する大気イオン化装置を除き、各機械はMEネットワークへ接続し、外部FEとネットワーク内のライトニングを使ってレシピを処理します。

<SubPages />

## 共有機能

### 自動エクスポート

ほとんどのマシンは **自動エクスポート** をサポートしています。有効にすると、マシンは処理が完了すると、許可された側の隣接するコンテナに出力をプッシュします。許可される側は、マシン GUI の「出力側の設定」画面で設定されます。

### スピードカード

結晶触媒装置を除くすべての加工機械は、処理速度を上げるAE2の**スピードカード**を最大4枚まで装着できます。

### ライトニング置換

超高電圧ライトニングを要求する一部のレシピは、**マトリクス代替**に対応しています。機械へ**ライトニング崩壊マトリクス**を装着すると、超高電圧の代わりに数倍量の高電圧ライトニングを消費して処理できます。交換比率はレシピごとに異なります。
