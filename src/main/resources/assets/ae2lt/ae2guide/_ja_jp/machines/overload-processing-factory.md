# オーバーロード処理工場

<Row>
  <BlockImage id="ae2lt:overload_processing_factory" scale="4" />
</Row>

**オーバーロード処理工場** は、この MOD で最大かつ最高のスループットの処理デバイスです。混合アイテムと流体 I/O をサポートし、ライトニング崩壊マトリクス を介した並列処理を可能にし、大規模な工業用 ライトニング生産ラインのバックボーンとなります。

## スロットと容量

| スロット/コンポーネント | 容量 | 注記 |
|------------------|----------|-------|
| アイテム投入×9 | 16,384 | アイテムを入力してください |
| マトリクス×1 | 32 | ライトニング行列を折りたたんで並列処理のロックを解除するをインストールします |
| アイテム出力 × 1 | 16,384 | 処理された出力。機械のみによって書き込まれます |
| 流体入力 | 1,024,000 mB | 必要な流体をパイプを通して供給します |
| 流体出力 | 1,024,000 mB | 流体出力を保持 |
| FE バッファ | 640,000,000 FE (デフォルト) | 内蔵エネルギーバッファ |
| スピードカードスロット | — | 最大 4 枚の AE2スピード カード |

## 操作の流れ

1. アイテムと流体の入力を入力します
2. マシンは現在の入力を登録されたレシピと照合します
3. レシピが一致し、必要な ライトニングおよび FE が利用可能になると、処理が開始されます
4. FE は処理中に消費されます。アイテム入力、流体入力、ライトニングは操作の完了時に消費されます
5. アイテムと流体の出力はそれぞれの出力スロットに送られます

## 並列処理

<ItemImage id="ae2lt:lightning_collapse_matrix" scale="2" float="left" />

ファクトリの並列処理は、インストールされている **ライトニング崩壊行列** の数によって決まります。マトリクススロットは最大 32 個のマトリクスを保持し、各マトリクスが構成可能な並列処理量を提供します (デフォルトはマトリクスごとに 8、最大 32 × 8 = 256)。

ライトニング崩壊マトリクスを持ち、オーバーロード処理工場を**スニークしながら使用**すると、マトリクススロットへ直接装着できます。最大32個までまとめて入り、余った分は手元に残ります。

* マトリクスがインストールされていないと、ファクトリは並列化できません
* より多くのマトリクスを直線的にインストールすると、平行上限が上がります
* 効果的な並列処理は、利用可能な入力マテリアルと各レシピの操作ごとのコストによっても制限されます
* 並列処理が高くなると、サイクルあたりの出力が増加し、合計 FE コストが高くなります。合計 FE コストでは、単純な線形乗数ではなく、工場の並列スケーリング式が使用されます。

## スピードカードとエネルギー消費

オーバーロード処理工場 は最大 4 枚のスピード カードを受け入れます。各カードは、ティックごとの FE の上限を大幅に引き上げます。

| スピードカード | FE ティックあたりの上限 (デフォルト) |
|-------------|---------------------------|
| 0 | 400,000 FE |
| 1 | 2,000,000 FE |
| 2 | 8,000,000 FE |
| 3 | 32,000,000 FE |
| 4 | 128,000,000 FE |

## 流体 I/O

流体の入力および出力には、任意の流体パイプ システムを使用できます。入力スロットは、レシピに対して液体のタイプを厳密に検証します。

## 自動エクスポート

自動エクスポートを有効にすると、アイテム出力は許可された側の隣接するコンテナに自動的にプッシュされます。側面は、GUI の「出力側面の構成」画面で構成されます。

## 電源

オーバーロード処理工場 は側面の ** 外部 FE** によって駆動されます。MEネットワーク から AE を直接描画するわけではありません。任意の FE パイプまたはケーブルを使用して、電源をその側面の 1 つに接続します。
