# セレスティウィーヴ

  <ItemIcon id="ae2lt:celestweave_oculus" />
  <ItemIcon id="ae2lt:celestweave_core" />
  <ItemIcon id="ae2lt:celestweave_conduit" />
  <ItemIcon id="ae2lt:celestweave_stride" />
</ItemGrid>

**セレスティウィーヴ**はモジュラーアーマーセットです。各ピースには独自の FE バッファ、ネットワーク バインディング、コア スロット、およびモジュール スロットがあります。

| ピース | アーマースロット | モジュール スロット |
|-------|------------|--------------|
| セレスティウィーヴオキュラス | ヘルメット | 4 |
| セレスティウィーヴコア | チェストプレート | 5 |
| セレスティウィーヴコンジット | レギンス | 4 |
| セレスティウィーヴストライド | ブーツ | 4 |

## アセンブリ

各部分に <ItemLink id="ae2lt:overload_device_workbench" /> を使用します。

1. 装甲部分を挿入します。ワークベンチの MEネットワーク にバインドされます
2. <ItemLink id="ae2lt:ultimate_overload_core" /> をコアスロットに取り付けます
3. 1 つのオプションの エネルギーモジュール と互換性のある装甲モジュールをインストールします
4. アーマーを装備し、デフォルトのキー G で オーバーロード装置ハブ を開いてモジュールを有効、無効、または設定します

エネルギーモジュール も 1 つのモジュール スロットを占有します。 エネルギーモジュール がない場合、各ピースには 10,000,000 FE が保存されます。 T1 / T2 / T3 モジュールは装甲容量を 1,000,000,000 / 5,000,000,000 / 20,000,000,000 FE に増加させます。

## ランタイム

モジュールは、その装甲部分が装備され、コアがインストールされ、モジュールが有効になっている場合にのみ機能します。アクティブなモジュールは、摩耗した セレスティウィーヴのピースから [FE を消費し、通常はバインドされた MEネットワーク から ライトニングを消費します。

FE または必須の ライトニングが欠落している場合、影響を受ける効果は維持できません。

## ヘルメットモジュール

| モジュール | 効果 |
|--------|--------|
| 暗視 | アクティブの間、暗視 を維持します |
| 水中呼吸 | アクティブの間、水中呼吸 を維持します |
| 満腹度維持 | 食料と飽和度を満腹に向けて回復し、回復時に HV を消費します |

## チェストプレートモジュール

| モジュール | 効果 |
|--------|--------|
| リーチ拡張 | ブロック/エンティティ相互作用範囲を追加します。 1x、2x、または 4x として構成可能 |
| マトリクスシールド | 環境ダメージをキャンセルして火を消し、通常ダメージを約80%軽減、ハードダメージを約50%軽減 |
| フェーズシールド | 受けるダメージを完全にブロックし、火災を消し、防止されたダメージに基づいて EHV を消費します |
| 反映する | 攻撃者のダメージの最大 30% を反射し、FE と HV を消費します |
| 不死 | 致命的なダメージを阻止し、FE と EHV のコストを多額に費やします |
| 浄化 | 設定されたステータス効果を削除してブロックします。デフォルトでは有害な影響のみ |

マトリクスシールド と フェーズシールド は同じインストール グループを共有しているため、チェストプレートにインストールできるのはそのうちの 1 つだけです。

## レギンスモジュール

| モジュール | 効果 |
|--------|--------|
| クリエイティブ飛行 | クリエイティブなスタイルの飛行を許可します。速度と慣性は設定可能です |
| フェーズフライト | ゲームモードを切り替えることなくブロックを飛行できるようになります。速度と慣性は設定可能です |

クリエイティブ飛行 と フェーズフライト は同じインストール グループを共有しているため、レギンスにインストールできるのは 1 つだけです。 フェーズフライト はインストール後にデフォルトで無効になっており、デバイス ハブで有効にする必要があります。

## ブーツモジュール

| モジュール | 効果 |
|--------|--------|
| ダッシュ | ダッシュ キー (デフォルトは V) を押して前方にダッシュします。 40ティックのクールダウン |
| 採掘適性 | 水中および空中での採掘ペナルティを補償します |

## コストメモ

最もアクティブなモジュールは、FE のドレインに加えて、ティックごとに 1 HV を消費します。 クリエイティブ飛行 は飛行中により多くの HV を消費し、フェーズフライト はティックごとに EHV を消費します。シールド、浄化、不死のコストは、短期間に繰り返し発動すると増加します。
