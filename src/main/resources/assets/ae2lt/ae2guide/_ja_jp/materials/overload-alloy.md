# オーバーロード合金

  <ItemIcon id="ae2lt:overload_alloy_blank" />

  <ItemIcon id="ae2lt:overload_alloy_plate" />

**オーバーロード合金** は、マシンフレーム、オーバーロードMEコントローラー、およびいくつかの最終層コンポーネントを含む、多くの高層レシピで使用される高度な金属材料です。

## 処理チェーン

1. **未加工オーバーロード合金** — 作業台で作成
2. **オーバーロード合金** - ライトニングシミュレーション室のブランクから精製されるか、または金属および結晶コンポーネントからオーバーロード処理工場でバッチ生産された完成した合金インゴット
3. **オーバーロード合金板** — ライトニングシミュレーション室 または オーバーロード処理工場 の オーバーロード合金 から押されました。 究極オーバーロードコア などの最上位のレシピで必要

<RecipeFor id="ae2lt:overload_alloy_blank" />

オーバーロード合金 は 2 台のマシンから取得できます。

| マシン | 入力 | ライトニング | エネルギー | 出力 |
|---------|--------|-----------|--------|--------|
| ライトニングシミュレーション室 | `1` 未加工オーバーロード合金 + `4` オーバーロードクリスタルの粉 | `1` 高電圧ライトニング | `20,000` | `1` オーバーロード合金 |
| オーバーロード処理工場 | `1` 銅ブロック + `1` 鉄ブロック + `1` ゴールドブロック + `1` アメジストブロック + `1` エンダーアイ + `1` コーラスフルーツ | `1` 高電圧ライトニング | `100,000` | `27` オーバーロード合金 |

## アイテム

| アイテム | 役割 |
|------|------|
| 未加工オーバーロード合金 | 生の中間生成物 |
| オーバーロード合金 | 完成した合金インゴット、ほとんどのオーバーロードマシンの主要な製作材料 |
| オーバーロード合金板 | プレスプレート形式。究極オーバーロードコア などの高度なレシピで使用されます。 |
