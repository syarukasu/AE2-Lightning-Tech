# 素材とアイテム

AE2 Lightning Tech では、大量の新しいマテリアルのセットが紹介されています。以下のページでは、主要品目および材料群ごとに詳しく説明しています。

<SubPages />

## 天穹素材

天穹 マテリアルはエンドティアラインです: 天穹の粉 (エンドでのみ入手可能) から始まり、天穹変換コア と オーバーロード処理工場 を経て セレスティウィーヴアーマーセットのコアコンポーネントと電磁レールガン。 [天穹素材](firmament-materials.md)を参照してください。

## 浮遊物質

浮遊物質 はシュルカー発射体捕獲材です。アクティブなMEネットワークに接続されているシルクタッチ <ItemLink id="ae2:annihilation_plane" />は、到達したシュルカー発射体を消費し、<ItemLink id="ae2lt:floating_matter" />をストレージに挿入できます。 [浮遊物質](floating-matter.md)を参照してください。

<ItemGrid>
  <ItemIcon id="ae2lt:floating_matter" />
</ItemGrid>

## 天候凝縮液

天候凝縮液 アイテムは、世界の天候を制御するために [大気イオン化装置](../machines/atmospheric-ionizer.md) によって消費されます。これらは ライトニングシミュレーション室、ライトニング組立室、または オーバーロード処理工場 で生成されます。
