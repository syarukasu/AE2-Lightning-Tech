# 過負荷のネットワーク

AE2 Lightning Tech は、大規模な拠点が標準の AE2のチャネルと容量の制限を突破できる「オーバーロード」ネットワーク デバイス ファミリを提供します。

バニラとの比較:

* 各 **オーバーロードMEコントローラー** ごとに 128 チャネルがネットワークに追加されます
* オーバーロードケーブル にはケーブルごとのチャネル制限はありません。オーバーロードされたネットワーク全体が、コントローラーの合計数に基づいてチャネルをグローバルに割り当てます。
* オーバーロードパターンプロバイダー および オーバーロードMEインターフェース にはそれぞれ 36 個のスロットがあり、設定可能な距離にわたる同次元の無線接続をサポートします
