# オーバーロードMEインターフェース

<Row>
  <BlockImage id="ae2lt:overloaded_interface" scale="4" />
</Row>

**オーバーロードMEインターフェース**は、通常の<ItemLink id="ae2:interface" />を強化した機器です。**36個の設定スロット**と、長距離のアイテム転送・エネルギー分配に使える**無線モード**を備えます。

## コア機能

* **36 構成スロット** (バニラには 9 つあります)
* **2つの動作モード**: 通常モードと無線モード
* **無制限モードスロット**: 個々のスロットを無制限の供給に切り替えることができます
* **2 つの I/O 速度**: 通常および高速 (プローブ)
* **エネルギー転送**: MEネットワークに保存されているFEを隣接するマシンまたは無線接続されたマシンにルーティングできます
* **インポートフィルタリング**: オーバーロードされたフィルタコンポーネントを使用して、インポートできる項目を制限します

## 動作モード

### 通常モード

通常モードでは、オーバーロードMEインターフェース はバニラ インターフェースのように動作します。設定に従って在庫を保持し、物理的に隣接するコンテナにアイテムを出力します。違いは、より多くの構成スロットとより高い転送帯域幅です。

エネルギー出力方向が設定されている場合、通常モードは FE を MEネットワーク からその側の隣接デバイスにルーティングすることもできます。

### 無線モード

無線モードでは、オーバーロードMEインターフェース は複数のマシンの入力、出力、エネルギー供給をリモートで管理できます。

**オーバーロード無線接続ツール** を使用して無線接続を確立します。

1. ツールを持ち、オーバーロードMEインターフェースを**右クリック**して選択します
2. ターゲット マシンの特定の面を右クリックして接続します
3. 1 つのインターフェースで複数のリモート マシンにバインド可能

無線リンクは、デフォルトで同じディメンション内にあり、**128 ブロック** 以内にある必要があります。距離制限は構成可能です。 0 に設定すると制限が無効になります。 1 つのインターフェースは最大 **1,024** の無線フェイス接続を保存でき、同じターゲットの異なるフェイスを個別にバインドできます。 **Ctrl** を押しながらターゲットを右クリックすると、同じタイプの連続するマシンを一括で切り替えます。

## インポート / エクスポート モード

| モード | 説明 |
|------|-------------|
| エクスポート: OFF | 項目をリモート マシンにエクスポートしません |
| エクスポート: AUTO | スロット構成に従ってアイテムをリモート マシンに自動的にエクスポートします |
| インポート: OFF | リモートマシンから項目をインポートしません |
| インポート: AUTO | アイテムをリモート マシンから MEネットワーク に継続的にインポートします |
| インポート: EJECT | リモート マシンは項目を仮想入力スロットにプッシュします。インターフェースはそれらを受動的に受け入れます |

## I/O 速度

| 速度階層 | 適応クールダウン範囲 | 説明 |
|------------|-------------------------|-------------|
| 通常 | 5 ～ 80 ティック | 一般的な使用に適しています |
| 高速 (プローブ) | 1 ～ 40 ティック | プローブ機構を使用して準備完了を早期に検出します。スピードカードが必要です |

インターフェースは適応型クールダウンを使用します。アイテムを移動できる場合はクールダウンが短くなり、何もすることがない場合は長くなり、パフォーマンスと応答性のバランスがとれます。

## 無制限モード

Shift キーを押しながら設定スロットをクリックすると、**無制限モード**に切り替わります。このモードでは、スロットは設定されたアイテムをリモート マシンに無制限に継続的に供給します。

## ME電力コスト

転送は MEネットワーク の電力を消費します。大規模なインポートまたはエクスポートの場合は、ネットワークに十分な AE のエネルギー バッファがあることを確認してください。電力が不十分な場合、転送は一時停止するか、ネットワークがサポートできるものだけを移動します。

## インポートフィルター

<ItemImage id="ae2lt:overloaded_filter_component" scale="2" float="left" />

オーバーロードMEインターフェース は、**オーバーロードされたフィルター コンポーネント** を受け入れて、MEネットワーク にインポートできる項目を制限します。フィルター コンポーネントは、AE2セルワークベンチ 構成と同じ方法で構成されます。

## エネルギー伝達

AppFlux誘導カードを装着すると（AppFluxが必要）、オーバーロードMEインターフェースからMEネットワーク内のFEを接続先の機械へ送れます。

* **通常モード**: 構成された側の隣接するブロックにエネルギーをルーティングします
* **無線モード**: ラウンドロビン スケジューラを介して、無線接続されているすべてのマシンにエネルギーを分配します。

## 自動化のヒント

* 単一のインターフェースで多くのマシンの I/O を無線で管理でき、多くの配管を置き換えることができます
* 無制限モードのスロットと組み合わせると、リモート マシンに特定のマテリアルを継続的に供給し続けることができます
* エネルギー伝送により、専用の電力線は不要になります
* 高速プローブ層を有効にして、処理応答レイテンシを短縮します
